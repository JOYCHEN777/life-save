- 中文：随手存档。
- 英文：Life Save。
- 当前文档组合写法：随手存档 · Life Save。
- 仓库标识：life-save。
- 用户反馈（2026-10-23）：“先记下”“其实还不错”；已明确要求保留为候选，并继续探索更简约、更抓人的表达。
- 这是既有原型的暂用名称，尚未最终定为对外品牌；本轮没有修改 App 展示名、仓库名或存档路径。

## “金鱼记忆”方向分析（助手建议，未定名）

- 场景联想：借用人们将“金鱼记忆”与容易忘事联系起来的文化意象，呼应记不清上次操作、需要随手记录的使用场景；不将“鱼只有几秒记忆”作为科学事实或产品宣传依据。
- 视觉与交互：金鱼是具体、可识别的形象，可以探索小鱼图标、记录后的气泡反馈、翻出回忆的轻动效。这里只是品牌表达候选，不将宠物养成或新的小世界玩法自动加入开发范围。
- 名称理解：完整名字可能让首次接触的人联想到记忆训练工具，也更强调“健忘”；可用明确的生活记录副标题表达实际用途，避免对用户做负面评价。
- 同方向变体：“金鱼记”更短，兼具金鱼形象与记录含义；“小金鱼”更偏陪伴，需要副标题说明用途。这两个变体由助手提出，用户尚未确认。
- 助手当前倾向把“金鱼记”与“存个档”作为两种不同气质比较：前者有角色形象与亲近感，后者有口语化的游戏存档含义。候选文案：“金鱼记——生活小事，替你收好。”尚未做名称可用性检索。

## 金鱼隐喻的进一步探索（2026-10-23）

- 用户最新反馈：“金鱼”有点土，希望可爱、有特点，同时保留金鱼的隐喻。尚未选定“金鱼记”，接下来优先探索声音、气泡、游动或尾巴等间接表达。
- 助手建议：名称承载小鱼的声音或动作，金鱼形象放在图标和轻动效中，两者共同传达品牌；不要求名称直接出现“鱼”或“记”。

| 助手候选（用户尚未确认） | 命名联想与气质 |
| --- | --- |
| 啵噜 | 拟声命名，像小鱼吐出一串气泡；圆润、可爱，也可以作为角色名字 |
| 咕噜 | 水下冒泡的声音，读写自然，有轻松、憨憨的感觉；词语本身联想较广 |
| 冒个泡 | 从水中气泡借到日常表达，点一下留个记录、偶尔向朋友露个面，动作含义清楚 |
| 一尾 | 一尾小鱼，简约、含蓄，气质更安静精致，可爱感更多依靠图形 |

本轮助手重点比较“啵噜”的角色感与“冒个泡”的动作感。“咕噜”是读写更自然的备选。以上是创意候选，尚未开展名称可用性检索，也不自动加入角色养成或好友功能。

## 后续讨论方式

逐个分析名称的含义与情绪、适合的产品、记忆与传播、可发展的视觉和交互，再比较哪个适合当前 App、哪个适合保留给未来产品。当前尚未开展名称可用性检索，也未选择胜出方案。
