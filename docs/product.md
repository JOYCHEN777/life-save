# 产品方向

## 已确认

- 核心用途：日常随手记录与查看，帮助记住生活状态。
- 首要体验：每次点击立即获得清晰、愉快的反馈。
- 优先交互：按下时有压感，完成后回弹，时间状态立即更新，并提供可关闭的音效。
- 长期希望覆盖多个平台，第一版允许先从简单形态验证。
- 宠物与世界养成后续考虑；MBTI 个性化、了解自己、寻找合拍的人和活动均不是本轮实现重点。

## 第一版候选范围

以下是待实现和进一步确认的产品范围，不代表当前原型已具备：

1. 自定义生活卡片和名称。
2. 一键记录当前时间，支持撤销误触与补记过去发生的事件。
3. 首页显示上次记录时间与已过去的时长。
4. 查看、修正历史记录。
5. 可靠的本地保存；保存失败时明确提示，不能仅凭动画宣告保存成功。
6. 统一的即时反馈，兼容关闭声音与减少动态效果的偏好。

## 当前原型

仅使用示例数据验证单张记录卡的体验：一键记录、状态更新、短动画、可选音效、记录列表、撤销和反馈重播。反馈重播不新增事件。演示状态与真实生活记录必须区分。

交互节奏目标：按压反馈立即开始，状态更新不等待动画结束，一次成功动画约在 0.8 秒内结束。该时长是设计目标，仍需真机验证手感与性能。

## 数据与反馈边界

- 记录事件的实际发生时间，补记时间与发生时间应区分。
- 撤销或修正后，重新从有效记录计算“上次发生时间”。
- 重复点击不能意外产生重复事件。
- 用药卡展示距上次服药记录的时间，不能根据没有记录推断没有服药。
- 用药观察依照用户与医生确认的方案，记录客观时间和症状；不把少吃药、延长停药或多次服药设计成得分目标。
- 原型中的健康类卡片与时间均为演示内容，不承载真实健康数据。

## 待验证

- 高频用户是否能在几秒内完成记录并退出。
- 动画和音效在反复使用后是否仍然舒适。
- 主要入口选择：App 首页、桌面小组件、快捷操作等。
- 首发平台和技术栈，以及原生触感的重要程度。
- 本地数据的备份与恢复方式；是否需要登录与跨端同步。

## 后续方向

真实使用记录形成个人规律；按偏好调整展示和反馈；宠物或世界养成；活动发现与社交。后续功能应在核心记录体验验证后分别评估。
