# 随手存档 · Life Save

一个帮助用户随手记录生活小事、快速查看上次发生时间的应用。第一版优先打磨每次点击的即时反馈：按压、回弹、状态更新和可关闭的短音效。

## 当前状态

项目处于交互原型阶段，包含示例数据的记录卡片。可体验一键记录、查看记录、撤销，以及不新增记录的反馈重播。尚未实现真实记录存储、补记、提醒、多端同步或原生震动。

## 本地预览

在项目根目录运行：

```sh
python3 -m http.server 8080 --bind 127.0.0.1
```

打开 <http://127.0.0.1:8080/prototype/>。音效默认关闭，可手动开启；浏览器不支持音频时仍可体验视觉反馈。

## 文件

- `prototype/index.html`：可独立预览的网页原型。
- `prototype/feedback.fragment.html`：对话内交互原型的可编辑源。
- `docs/product.md`：已确认方向、第一版候选范围和待验证事项。

两个原型文件包含同一份交互设计。修改时需同步并验证，避免预览与源文件不一致。正式应用的技术栈尚未确定。

## 设计原则

- 快速记录，快速查看，误触可以撤销。
- 反馈短促明确，不阻挡下一次操作。
- 漏记后可以继续使用，不引入断签惩罚。
- 用药示例展示距上次**记录**的时间，未记录不等于未服药；奖励准确记录，不奖励增加服药次数或延长停药时间。

宠物和世界养成、MBTI 个性化、社交与活动探索作为后续方向。
