# 随手存档 · Life Save

一个帮助用户随手记录生活小事、快速查看上次发生时间的应用。第一版优先打磨每次点击的即时反馈：按压、回弹、状态更新和可关闭的短音效。

## 当前状态

项目处于可本机试用的第一版阶段，使用原生 HTML、CSS 和 JavaScript，无安装依赖或构建步骤。

- 可展开的左侧菜单： 首页、场景清单、全部卡片、记录日历、设置；手机上显示为抽屉。
- 自定义生活卡片：设置名称、图标、用途、场景和提醒规则。
- 随手记录：每次点击保存实际时间，短暂防连点后可继续新增；按卡片撤销最近一次。
- 提醒进度条：从上次记录后计算间隔，或每天固定时间；显示剩余时长、目标时间和已到期状态。
- 一键确认：出门前按手动开启的轮次确认，猫咪照顾和独立确认卡按本机日期每日确认。新一轮保留历史，本轮不重复确认。
- 本地保存、方格日历、可关闭的提示音和轻量反馈设置。

提醒目前只在页面内展示，关闭页面后不会发送系统通知。尚未实现补记、历史编辑、卡片删除、备份、多端同步或原生震动。

记录日历按本机日期汇总，默认展示近 12 周，可翻页查看更早日期。绿色方格表示当天有记录，点击方格可查看当天的具体时间。同一天多条记录仍显示一格绿色，数量在详情中展示；新增和撤销后同步更新。

清除浏览器数据或更换浏览器不会保留这些本地记录。首次打开会自动迁移同一路径下旧版真实服药记录并保留原始存储副本；旧版写死的示例记录不迁移为真实记录。非法数据不会被自动覆盖，写入失败不会显示成功。

## 本地预览

在项目根目录运行：

```sh
python3 -m http.server 8080 --bind 127.0.0.1
```

打开 <http://127.0.0.1:8080/prototype/>。音效默认关闭，可手动开启；浏览器不支持音频时仍可体验视觉反馈。

## 文件

- `prototype/index.html`：网页入口与应用布局。
- `prototype/app.js`：页面、卡片、菜单和交互。
- `prototype/styles.css`：响应式样式及点击反馈。
- `prototype/model.js`：记录、确认轮次、提醒及日历规则。
- `prototype/store.js`：本地保存、旧数据迁移和多标签页更新冲突检测。
- `prototype/*.test.mjs`：数据迁移、保存失败、确认轮次和日期计算测试。
- `docs/product.md`：已确认方向、第一版候选范围和待验证事项。

网页已从旧的 iframe 原型迁入独立页面，不再使用 fragment 渲染脚本。原生客户端技术栈尚未确定。

运行逻辑测试：

```sh
cd prototype
npm test
```

浏览器交互测试可使用 `http://127.0.0.1:8080/prototype/?check=v3`，查询参数对应独立存储空间，避免测试数据混入正式试用记录。

## 设计原则

- 快速记录，快速查看，误触可以撤销最近一次；短暂防连点后可以继续记。
- 反馈短促明确，不阻挡下一次操作。
- 漏记后可以继续使用，不引入断签惩罚。
- 用药示例展示距上次**记录**的时间，未记录不等于未服药；奖励准确记录，不奖励增加服药次数或延长停药时间。

宠物和世界养成、MBTI 个性化、社交与活动探索作为后续方向。
