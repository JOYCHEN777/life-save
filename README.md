# 随手存档 · Life Save

一个帮助用户随手记录生活小事、快速查看上次发生时间的应用。第一版优先打磨每次点击的即时反馈：按压、回弹、状态更新和可关闭的短音效。

## 当前状态

项目处于可本机试用的第一版阶段，使用原生 HTML、CSS 和 JavaScript；本批 LS-17-A 已接入 Node 内置 SQLite 本机服务，无外部 npm 依赖或构建步骤。

- 可展开的左侧菜单： 首页、场景清单、全部卡片、记录日历、生活动态、设置；手机上显示为抽屉。
- 自定义生活卡片：设置名称、图标、用途、场景和提醒规则。
- 随手记录：每次点击保存实际时间，短暂防连点后可继续新增；按卡片撤销最近一次。
- 提醒进度条：从上次记录后计算间隔，或每天固定时间；显示剩余时长、目标时间和已到期状态。
- 一键确认：出门前按手动开启的轮次确认，猫咪照顾和独立确认卡按本机日期每日确认。新一轮保留历史，本轮不重复确认。
- 记录日历：总览按次数加深绿色；分类按事项展示彩色小方块，点日期可看次数、时间与备注。
- 「补一句」：完成后可忽略、可稍后补写，每段备注归属于具体的一次记录；可修改或清空。
- 「生活动态」：集中回看记录与备注，支持独立随手记、修改文字，以及备注／随手记筛选。
- 「翻翻以前」：首页从今天之前的真实随手记或带备注记录中随机翻看，支持同轮去重和进入原记录。
- 「外观与皮肤」：设置六套预设皮肤，支持预览、应用、恢复默认和本机自定义壁纸；外观数据独立保存，不影响生活记录。
- 本机 SQLite 正式存档：卡片、场景、历史记录、备注、随手记、确认轮次、提醒规则、主题、壁纸和操作偏好均由同一本地服务保存。

提醒目前只在页面内展示，关闭页面后不会发送系统通知。尚未实现补记过去的操作、修改历史操作时间、卡片删除、随手记删除、完整备份管理界面、多端同步或原生震动。

记录日历按本机日期汇总，默认展示近 12 周，可翻页查看更早日期。总览及单卡详情使用固定次数档位（0、1、2–3、4–6、7+）；分类包括出门前、猫咪照顾、随手记录和独立确认，按当前卡片分组显示。每项每天显示一个固定位置的小方块，重复操作的次数在日期详情中查看；超过四项时显示前三项及其余已记录事项的 +N 提示。新增和撤销同步更新。备注和独立随手记不增加卡片记录次数。

正式记录不再以浏览器 `localStorage` 作为运行时存档；清除某个浏览器的站点数据后，重新连接本机服务仍可读取 SQLite 正式存档。旧 `localStorage` 会保留为迁移来源，不能跨浏览器直接互读；设置页先展示来源摘要和合并预览，再由用户选择迁入方式。非法来源不会被自动覆盖，写入失败不会显示成功。

旧版 v3/v4 的浏览器存储兼容代码仍保留在 `prototype/store.js`，仅用于来源迁移和回归测试，不代表当前页面继续把浏览器存储当正式档案。

## 本地预览

在项目根目录启动本机 SQLite 服务：

```sh
node prototype/server.mjs
```

打开 <http://127.0.0.1:8787/prototype/>。服务默认只监听 `127.0.0.1:8787`，正式数据目录为 macOS 的 `~/Library/Application Support/Life Save`；可用 `LIFE_SAVE_DATA_DIR=/path/to/data node prototype/server.mjs` 指定开发验证目录。若使用 Python 在 `8080` 提供页面，SQLite 服务仍必须保持运行，页面会连接 `8787`。

音效默认关闭，可手动开启；浏览器不支持音频时仍可体验视觉反馈。当前命令是开发启动方式，不是未来安装版；安装版自动启动、退出管理和无开发环境安装尚未交付。

## 文件

- `prototype/index.html`：网页入口与应用布局。
- `prototype/app.js`：页面、卡片、菜单和交互。
- `prototype/styles.css`：响应式样式及点击反馈。
- `prototype/model.js`：记录、确认轮次、提醒及日历规则。
- `prototype/store.js`：本地保存、旧数据迁移和多标签页更新冲突检测。
- `prototype/appearance.js`：预设皮肤、壁纸校验和独立外观存储。
- `prototype/sqlite-store.js`：浏览器到本机 SQLite 服务的读取、action 写入和迁移客户端。
- `prototype/server.mjs`：本机 HTTP 服务、SQLite 事务、正式／测试空间、幂等写入、冲突检查和壁纸文件引用。
- `prototype/*test.mjs`：数据模型、旧存档兼容、SQLite HTTP 服务、并发、幂等、冲突、迁移和外观测试。
- `docs/product.md`：需求主文档，包含 LS-01～LS-18、待定设计、现有实现基线和跨对话交接约定。

网页已从旧的 iframe 原型迁入独立页面，不再使用 fragment 渲染脚本。原生客户端技术栈尚未确定。

运行逻辑测试：

```sh
cd prototype
npm test
```

浏览器交互测试可使用 `http://127.0.0.1:8787/prototype/?check=notes-square-v4`，`check` 会映射到独立的服务端测试空间，避免测试数据混入正式存档。旧浏览器来源迁移必须在持有该 `localStorage` 的环境打开设置页操作。

## 设计原则

- 快速记录，快速查看，误触可以撤销最近一次；短暂防连点后可以继续记。
- 反馈短促明确，不阻挡下一次操作。
- 漏记后可以继续使用，不引入断签惩罚。
- 用药示例展示距上次**记录**的时间，未记录不等于未服药；奖励准确记录，不奖励增加服药次数或延长停药时间。
